# ResQNova

ResQNova is a command-center style emergency response platform foundation.

## Stack

- Frontend: Next.js 15, TypeScript, Tailwind CSS, shadcn/ui, Lucide React, Framer Motion
- Backend: FastAPI folder skeleton only for now

## Structure

- `frontend/` contains the Next.js app, shared components, and future feature folders
- `backend/` contains empty FastAPI-ready folders for future API work
- `docs/` is reserved for project documentation

## Current Scope

This batch only establishes the project foundation:

- global theme tokens and typography
- reusable UI building blocks
- landing screen and placeholder shell pages
- empty backend folder structure

Business logic, APIs, authentication, and maps are intentionally not implemented yet.
