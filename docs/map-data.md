# Digital Disaster Twin Map Data

The command center vendors the Andhra Pradesh district boundary GeoJSON at `frontend/public/data/andhra-pradesh-districts.geojson`.

Source: [Andhra Pradesh Open Data Locations](https://github.com/satishvmadala/andhrapradesh_opendata_locations), `AndhraPradesh_Districts.geojson`.

The source contains multipart geometry features representing 26 unique Andhra Pradesh districts. Leaflet renders the local asset so the dashboard does not depend on a runtime boundary-data request.
